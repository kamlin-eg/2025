موقع شركة كاملين – تعليمات سريعة

1) افتح assets/config.js
2) غيّر whatsappNumber إلى رقم واتساب الشركة بصيغة دولية من غير + أو مسافات.
   مثال مصر: 201xxxxxxxxx
3) غيّر phoneDisplay إذا رغبت.
4) ارفع جميع الملفات والمجلدات إلى مستودع GitHub ثم اربطه بـ Netlify.
5) الصفحة الرئيسية: index.html
6) لوحة الطلبات: admin.html

مهم:
- لوحة الطلبات الحالية تستخدم LocalStorage، أي أن البيانات تظهر فقط على نفس المتصفح والجهاز.
- للاستخدام الفعلي من عدة أجهزة يجب ربط النموذج بقاعدة بيانات Supabase مع تسجيل دخول آمن.
- الصور الحالية مستضافة من Unsplash ويمكن استبدالها بصور الشركة بوضع الصور داخل assets وتغيير روابط img.
