# Kamlin Complete v5

نسخة كاملة ونظيفة للموقع ونظام الإدارة.

- الموقع: `index.html`
- لوحة الإدارة: `admin.html`
- بيانات التواصل محدثة.
- صور الخدمات غير مستخدمة؛ الخدمات تعتمد على رموز/إيموجي خفيفة.
- لوحة الإدارة تشمل الطلبات، العمال، التكليفات، الحضور، تسليم الأدوات، العملاء، المتابعات، والعقود.
- لا يظهر أي تلميح لكلمة المرور في واجهة الدخول.
- التخزين الحالي LocalStorage، ويمكن نقله إلى Supabase لاحقًا.
