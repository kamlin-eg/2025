# متجر كاملين — نسخة جاهزة لـ GitHub Pages

واجهة عربية متجاوبة بالتركواز والأبيض، مع 3 اتجاهات تصميم، وأقسام المنتجات السودانية والعناية والعبايات والإكسسوارات، والبحث والمفضلة والسلة ومحرر المنتجات.

## الملفات

- `index.html`: الموقع كاملًا؛ HTML وCSS وJavaScript في ملف واحد.
- `.nojekyll`: تشغيل الملفات الثابتة دون معالجة Jekyll.
- `README.md`: تعليمات النشر والتحديث.

## الرفع لأول مرة

1. فك ضغط الحزمة على جهازك؛ لا ترفع ملف ZIP نفسه.
2. افتح مستودعًا مخصصًا لهذا المتجر في GitHub. إذا عندك موقع قائم، استخدم مستودعًا مستقلًا حتى لا تستبدل صفحته الرئيسية.
3. اختر Add file ثم Upload files وارفع الملفات إلى جذر المستودع، بحيث يظهر `index.html` مباشرة وليس داخل مجلد إضافي.
4. اضغط Commit changes.
5. افتح Settings ثم Pages.
6. في Source اختر Deploy from a branch.
7. اختر الفرع الذي رفعت عليه الملفات، مثل main، والمجلد /(root)، ثم Save.
8. انتظر اكتمال النشر. رابط الموقع يظهر في Settings → Pages.

إذا أخفى جهازك `.nojekyll`، تستطيع إضافته في GitHub عبر Add file → Create new file، باسم `.nojekyll` ومحتوى فارغ. لا يحتاج هذا الموقع إلى npm أو خطوة build.

## تغيير الأسعار والصور ونشرها لجميع الزوار

1. افتح الموقع واضغط «تعديل المنتجات والأسعار» أعلى الصفحة.
2. اختر المنتج، ثم عدّل الاسم والسعر والمصدر والوصف والقسم.
3. ارفع صورة JPG أو PNG أو WebP من جهازك، أو أضف رابط صورة HTTPS.
4. اضغط «حفظ التعديلات». هذا يحفظ التعديل في نفس المتصفح فقط.
5. بعد تعديل كل المنتجات المطلوبة، اضغط «تنزيل الموقع المعدّل»؛ الصور المرفوعة تُضمّن داخل الملف.
6. غيّر اسم الملف المنزّل من `Kamlin_Store_Edited.html` إلى `index.html`.
7. ارفعه إلى نفس المسار في المستودع ليحل محل `index.html`، ثم Commit changes.
8. بعد اكتمال نشر GitHub Pages، تحقق من الموقع في نافذة خاصة لرؤية النسخة المنشورة دون تعديلات محلية قديمة.

الصور كبيرة الحجم يتم تصغيرها عند رفعها. الصور الافتراضية وروابط الصور الخارجية تحتاج اتصالًا بالإنترنت. الصور التي ترفعها من جهازك تصبح جزءًا من ملف الموقع المنزّل.

## حدود النسخة الحالية

- المنتجات والأسعار الحالية أمثلة للمعاينة؛ ليست أسعار شي إن المعتمدة أو تأكيدًا لتوفر المنتجات.
- لا توجد بوابة دفع أو تسجيل طلبات أو مخزون مشترك أو حسابات عملاء.
- المحرر محلي ويمكن لأي زائر استخدامه لتعديل نسخته في متصفحه؛ لا يستطيع نشر تغييرات في مستودعك دون صلاحية GitHub.
- الحفظ المحلي مرتبط بالمتصفح والجهاز، وقد يضيع إذا حذفت بيانات الموقع. نزّل نسخة بعد تعديل الكتالوج.
- مسح بيانات المتصفح أو فتح الموقع في نافذة خاصة يعرض الكتالوج المنشور.
- لوجود لوحة إدارة محمية تحفظ تغييراتك لجميع الزوار فورًا، تحتاج هذه الواجهة إلى قاعدة بيانات ومصادقة وخادم خلفي.
- الحزمة لا تتضمن مفاتيح أو كلمات مرور أو بيانات حسابات.
